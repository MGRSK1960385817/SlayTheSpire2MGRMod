# 卡牌标题简短化修复记录

> 日期：2026-08-16  
> 状态：英文基准及全部现有语言已修复  
> 范围：仅修正标题与 `Yaaaaaa` 的升级标题后缀，不改卡牌机制。

## 1. 本轮锁定

| 资源 key | 代码名给出的语义 | 英文锁定标题 |
|---|---|---|
| `MGR_MOD_CARD_PARANOIA_GIRL.title` | `PARANOIA_GIRL` | `Paranoia Girl` |
| `MGR_MOD_CARD_ODE_TO_ULTRAMARINE.title` | `ODE_TO_ULTRAMARINE` | `Ultramarine Hymn` |
| `MGR_MOD_CARD_WHITE_SOUTH_WIND.title` | `WHITE_SOUTH_WIND` | `White South Wind` |
| `MGR_MOD_CARD_MANIMANI.title` | 用户指定标题 | `Let It Be` |
| `MGR_MOD_CARD_RESONATE.title` | `RESONATE` | `Resonate` |
| `MGR_MOD_CARD_METEOR_AFTERMATH.title` | `METEOR_AFTERMATH` | `Meteor Aftermath` |

`MGR_MOD_CARD_YAAAAAA.upgradeTitleSuffix` 按目标语言的显示长度追加：简体中文、繁体中文、日语、韩语只追加一个字符（`啊`、`啊`、`あ`、`아`）；目前的拉丁字母语言追加两个字符 `aa`；俄语追加两个发声单位 `-а-а`。不得机械地让所有语言追加两个字符。基础标题若以 `h` 结尾并会形成 `...haa`，改用可直接追加 `aa` 的 `Yaaaaaa`。

## 2. 复用原则

- 这批标题以用户明确指定的代码名语义为准，不再恢复成难懂的日语歌名转写。
- 目标语言优先使用一至两个词；直译确实需要三个短词时可以保留，但不得扩写成长句。
- `Let It Be` 只锁定英语。日语恢复歌曲原题 `まにまに`；繁中采用 `隨之任之`；德语、法语、西班牙语和巴西葡萄牙语采用自然、简短的本地译名，不使用英文标题或原题音译；其他语言按各自指导裁决。

## 西方语言标题本地化追加裁决（2026-08-16）

- 德语、法语、西班牙语和巴西葡萄牙语的标题直接以简中 `zhs` 当前显示文本的语义为准；`DAYBREAK FRONTLINE`、`Higan`、`Shunran`、`Yuseiboushi`、`Karakuri Pierrot` 等国际标题或转写不再保留。
- 简中显示文本本身就是不可拆分拉丁字母名称时才原样保留，例如 `MGR`、`Fumo`、`Adios`。
- 卡牌名变化后必须同步同名能力、关键词正文和遗物标题；标题仍以一至两个词或等价紧凑词组为优先，允许为扫读性做无损压缩。
- 中文原文标题继续作为机制与创作语义基准；本记录只覆盖上表所列目标语言标题裁决及 `Yaaaaaa` 后缀。

## 4. 后续短标题修复

`MGR_MOD_CARD_PLEASING_GHOSTS.title` 的英文旧标题过长，现锁定为 `Pleasing Ghosts`。同步检查后采用：德语 `Geisterlob`、法语 `Plaire aux fantômes`、日语 `おばけのウケねらい`、韩语 `유령 아부`、俄语 `Угодить призракам`、西班牙语 `Agradar fantasmas`、巴西葡萄牙语 `Agradar Fantasmas`、繁中 `拍鬼怪的馬屁`。已有标题足够紧凑或属于自然短语时不强行缩写。

## 5. 光线歌与老大哥标题修复

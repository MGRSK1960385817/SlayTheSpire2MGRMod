# MGR 测试版角色选择卡顿排查

2026-11-15 收到一条最新测试版选人界面卡顿的反馈。玩家的具体游戏版本、模组列表、触发时机及帧时间未知，目前已完成静态检查和现有日志核对，仍需实机对照定位原因。

## 版本与检查范围

- 本机 `public-beta` 为 v0.113.1（`d09d48e5`）。工坊下载的 MGR 0.8.1 含 v0.113.0 payload，Loader 会在 v0.113.1 选用它。本机已有日志也确认了这一选择，RitsuLib 0.6.13 同样选用 v0.113.0 运行变体。该日志来自本地安装的 MGR 和其他模组同时启用的环境，未记录选人界面帧时间。
- 工坊下载包与本地工坊准备目录的 PCK、v0.113.0 payload 和变体清单 SHA-256 一致。已经直接核对下载包中的星空脚本和背景纹理导入数据。本机日志加载的是 `mods/MGRMod` 下的另一份 0.8.1，该份 PCK 与 payload 哈希不同。
- 反编译 v0.111.0、v0.113.0 与本机 v0.113.1 的原版选人界面。v0.113.0 新增记忆上次游玩角色的行为，v0.113.1 仍会在打开标准选人时自动选择该角色，并同步执行选人音效、获取及实例化背景场景和刷新角色数据。v0.113.1 保留了 v0.113.0 的背景实例化链。若玩家上局用歌姬，进入界面时就可能出现原本需要切到歌姬才出现的负担。
- 原版公告见 [v0.113.0 更新](https://steamcommunity.com/games/2868840/announcements/detail/708914333639245838)及 [v0.113.1 热修](https://steamcommunity.com/games/2868840/announcements/detail/708914425087656683)。v0.113.0 压缩了原版选人纹理。工坊 MGR 自带背景仍为 2520 × 1320 的非 VRAM 压缩纹理，PCK 中的 `.ctex` 约 4.61 MiB。

## 按可观察症状排查

| 症状 | 优先检查 | 已知证据 |
| --- | --- | --- |
| 停在歌姬时持续掉帧，换原版角色后恢复 | 程序化星空的每帧重绘 | `MgrCharacterSelectStars._Process()` 每帧调用 `QueueRedraw()`。默认的光带、星座、流星和散星合计约 456 次 Godot 绘图 API 调用及 7 个临时顶点数组每次重绘。许多线段启用抗锯齿，图元调用数不能直接换算成 GPU draw calls。该实现自 2026-08-16 起未改动。“关闭人物动画”只控制人物逐帧贴图及常驻角色特效，当前不覆盖选人星空。 |
| 进入界面或第一次切到歌姬时顿一下，随后流畅 | 冷加载、上传背景纹理、场景实例化与星空初始化 | 原版主菜单会预加载角色选择资源。若打开界面早于后台预加载完成，或对应路径未命中缓存，背景获取可回退到同步加载。实例化、`_Ready()` 和首次重绘仍发生在切换过程中。本机现有日志未命中 MGR 选人背景的 `Asset not cached`，也没有该段帧时间，无法确认玩家遇到冷加载。 |
| 切到其他角色也卡，或只在同时启用其他模组时出现 | 原版菜单预加载、选人补丁和模组组合 | 本机日志同时出现 BaseLib 的选人滚动条补丁和 Loadout 的菜单预热。日志中的 `GetProfileDir` Harmony 异常归属 SavesMerger 初始化。目前无证据将这些现象归为该玩家的原因。 |
| 选择歌姬后无选择音效、界面长时间冻结或闪退 | 复现时的 `godot.log` 和 FMOD 播放路径 | 旧报告涉及同步创建 OGG 声音对象。当前 MGR 使用已注册的 FMOD Bank 事件播放。本机日志有 Bank 注册和 GUID 映射成功信息，旧 OGG 路径已移除。 |

## 实机对照

- 优先请玩家提供标题画面的版本号，并确认卡顿发生在进界面时、切到歌姬时还是停在歌姬时，以及换到铁甲战士是否恢复。短录屏足够区分触发时机。Windows 复现日志位于 `%APPDATA%\SlayTheSpire2\logs\godot.log`。
- 在同一客户端先用原版作为基线，再启用 MGR 与 RitsuLib，比较首次进入、首次切歌姬、停留、切回原版和再次切歌姬。记录首帧尖峰及稳定帧时间，并确认实际加载路径和版本。需要核对模组交互时，再逐个加回修改选人界面的模组。
- 若持续掉帧可复现，用同一背景图做星空显示开关的 A/B 对照。若只出现首切尖峰，分别计时缓存获取、实例化和首绘。根据结果决定是否将星空接入现有性能开关、降低重绘开销，或调整背景加载与纹理导入。

本轮产物为排查记录，实机帧时间和玩家侧复现仍待补充。

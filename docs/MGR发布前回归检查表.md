## 一、启动与生命周期

- [ ] 只安装 MGR 与声明的 RitsuLib 依赖时可以进入主菜单。
- [ ] 可以选择 MGR、新建对局并进入第一场战斗。
- [ ] 保存退出后可以继续对局，音符、演奏牌、卡牌永久数值与遗物计数正确。
- [ ] 普通战斗、精英、Boss 胜利后可以正常进入奖励和下一节点。
- [ ] 角色死亡与通关结算正常，无残留 UI 或未结束动作。
- [ ] 地图、牌组、抽牌堆、弃牌堆与消耗堆界面打开时，音符槽和演奏线谱正确隐藏。

## 二、音符与和弦

- [ ] 攻击、技能、能力、状态、诅咒正确映射为对应基础音符。
- [ ] 星空、幽灵、万象及特殊映射正确，任务牌按规则映射为诅咒音符。
- [ ] 自动打出、生成牌、弃牌转化与消耗转化不会漏记或重复生成音符。
- [ ] 空槽、满槽、容量增加/减少及槽位 UI 与实际数据一致。
- [ ] 和弦按槽位顺序结算；重复和弦的次数、动画与效果一致。
- [ ] 强音只增强攻击、技能与能力音符，能力音符每 2 层强音增加 1 张抽牌。
- [ ] 状态与诅咒音符不受强音影响；幽灵音符给予无实体；万象同时结算六种效果。
- [ ] 大量连续生成和触发时动画能加速，但不会漏结算、错位或卡死。

## 三、演奏

- [ ] 普通攻击、技能、能力、状态、诅咒与 X 费牌均可进入演奏队列。
- [ ] 打出本身不扣演奏次数；从下个回合开始按入队顺序结算。
- [ ] 演奏剩余次数、队列上方数字、放大预览和实际效果一致。
- [ ] 演奏自然结束后，消耗/弃牌/能力牌去向正确，牌堆计数立即刷新。
- [ ] 通过特殊效果直接入队且原本没有演奏的牌，队列数字显示为 1。
- [ ] 胆小鬼火箭在弃牌前进入队列；活动小丑交换后进入队列的诅咒演奏次数为 1。
- [ ] 立即触发、延长、结束全部演奏和演奏结束钩子不会递归自锁。
- [ ] 敌人全部死亡后立刻停止剩余演奏动作并进入结算。
- [ ] 演奏能力牌不会同时播放飞向人物与飞向队列的冲突动画。
- [ ] 十张以上演奏牌时堆叠、触发速度、扫线和特效仍可辨认且帧率可接受。

## 四、重点特殊卡

- [ ] 呀啊啊啊可以无限升级，名称与抽牌数每次各增加一次。
- [ ] 随之任之仅在合法斩杀目标上切换插图；斩杀后永久伤害正确写回牌组版本。
- [ ] 轩辕十四被丢弃或消耗时返回手牌、正确减费，且不会复制或卡在画面中央。
- [ ] 卡农形态从下一回合起按预期顺序复制上回合末尾卡牌，叠层后无递归失控。
- [ ] 狂性只允许并扣血打出原本不可打出的状态/诅咒；原本可打出的牌不扣血。
- [ ] 光线歌的三次牌堆选择层级正确，手牌不会遮挡选择界面。
- [ ] 游生梦死生成牌能快速进入手牌，并同时获得消耗、虚无及正确描述。
- [ ] 热异常的“基础伤害”包含锋利附魔，不包含力量与活力。
- [ ] 所有动态卡面数字在战斗外、奖励页和战斗内均不显示为 0 或错误表达式。

## 五、遗物与人物内容

- [ ] 初始遗物可被先古遗物正确替换。
- [ ] 节拍器跨战斗计数；记仇小本本累计旅途生命损失；黑金唱片只在演奏结束时结算。
- [ ] 苍白花、吉他拨片、小天使、迷你舞台与鮪鱼烧的触发时机和数值正确。
- [ ] MGR 的遗物奖励池不会出现已列入角色黑名单的遗物。
- [ ] 人物战斗、商店、营火与选人场景的大小、位置、阴影和特效正确。
- [ ] 先古对话只作用于 MGR，不覆盖原版或其他模组人物文本。

# MGR Steam 工坊本地化维护规则

本文件规定 MGR Steam 创意工坊十种语言标题与简介的长期维护方式。游戏内 JSON 本地化仍以 [`本地化翻译总指导.md`](本地化翻译总指导.md) 和对应语言指导为准。

## 一、权威源与文件位置

- 简体中文简介 `MGRWorkshop/descriptions/schinese.txt` 是工坊简介的语义权威源。
- 其余九种简介位于同一目录，必须直接从简体中文翻译，不以英语作为中间源。
- 十种语言标题分别保存于 `MGRWorkshop/titles/<Steam API 语言代码>.txt`；准确对照和当前标题见该目录的 `README.md`。
- 标题为单行纯文本，不使用 BBCode；简介使用 Steam Workshop 支持的 BBCode。
- Steam 标题最多使用 128 个 UTF-8 字节，简介必须低于 8000 个 UTF-8 字节；保存或上传前必须按字节而不是字符数检查。

## 三、非简体中文版本的永久排除项

用户所说的“无需翻译”在本项目中表示：从其他九种语言版本中整项删除，而不是保留简体中文原文。以下内容只允许出现在简体中文简介：

1. B站联系方式；
2. QQ 联系方式；
3. 包含“这句不用翻译”的整行文字；
4. “特别鸣谢”标题及其整个段落。

X、Discord、BUG 反馈方式以及其他普通内容应正常翻译并保留。

## 四、更新日志结构

简介末尾的玩家向更新日志固定分为：

1. `重大更新`：跨版本支持、新增重要设置或大型系统功能；
2. `BUG 修复`：崩溃、联机不同步、层级遮挡、存档丢失或卡牌效果错误；
3. `表现改善`：动画、特效、可读性及数值平衡调整。

每条使用一至两句话概括玩家能够观察到的结果，不复制内部原因分析、类名、哈希或构建细节。总变更记录新增玩家向条目后，下一次明确要求更新工坊简介时应同步十种语言的更新日志。

## 五、上传边界

- 普通内容发布默认不修改任何语言的标题和简介。
- 只有作者明确要求更新本地化标题、简介或两者时，才把对应目录交给上传器。
- 上传器可在同一个语言更新句柄中分别调用标题和简介更新；某语言只存在其中一个文件时，只更新存在的字段。
- 本地文件完成不代表已经发布；只有实际线上提交成功后才能记录为已发布。

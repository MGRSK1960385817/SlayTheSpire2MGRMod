# MGR 塔二版设计方向

## 保留的角色身份

- 歌姬主题、橙色视觉和迷你麦克风初始遗物。
- 出牌会形成音乐序列，序列完成后产生集中收益。
- 起音、尾音、强音和和弦仍是值得保留的设计语汇。

## 不直接迁移的底层实现

塔一版本把音符存进缺陷者的充能球槽，并用观者姿态实现“开眼”。塔二版不会继续覆盖其他角色的专属资源：

1. MGR 拥有独立的四拍“乐句”。
2. 出牌向乐句追加不同种类的音符。
3. 四个不同音符形成“和声”，提供额外律动。
4. 四个相同音符形成“回响”，使专精单一路线同样成立。
5. 律动由终演类卡牌主动消费，不自动切换到其他角色的姿态系统。

`Scripts/Mechanics/PhraseState.cs` 目前只实现与游戏无关的规则核心。等 UI、多人归属和存档方案明确后，再接入 RitsuLib 生命周期与次要资源系统。

## 迁移规则

不会批量翻译 94 张旧卡。每张旧卡必须单独归类：

- 保留身份，重写塔二实现；
- 围绕乐句/律动重做；
- 用全新的塔二卡牌替代；
- 退役。

当前只迁移了起始牌身份与必要美术：4 张打击、4 张防御、窥视、安眠曲和迷你麦克风。

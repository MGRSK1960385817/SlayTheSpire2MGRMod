# MGR 原版技能与能力特效盘点与分配建议

## 一、结论

本次检查基于本地反编译的《杀戮尖塔 2》原版源码，重点查看 `CardType.Skill`、`CardType.Power`、对应的 `PowerModel`，以及它们直接调用的 VFX/SFX。

- 整个原版卡牌源码目录中，共检查到 246 张技能牌与 113 张能力牌。这个数字包含无色牌、事件牌、先古牌和联机牌，主要用于观察实现比例，不等同于单个角色卡池数量。
- 只有 19 张技能牌显式创建了专属 VFX；其余绝大多数技能依赖格挡、抽牌、能量、选牌、牌堆移动、充能球等系统自带反馈。
- 只有 7 张能力牌在打出阶段显式创建了专属 VFX；绝大多数能力牌只播放通用能力牌动画、应用能力图标，并在真正触发时调用 `Flash()`。
- 原版能力视觉通常分为三层：**打出时演出**、**持续存在的角色附着效果**、**能力实际触发时的反馈**。三层并不要求同时存在。
- MGR 的音符、和弦与演奏已经有强烈的系统级视觉语言。涉及这些机制的卡牌应优先使用现有 UI 反馈，避免再叠加不必要的原版全屏特效。
- 进入演奏队列的技能或能力可能重复触发。大型暗角、长距离投射物、持续等待和能力牌飞向角色的动画必须谨慎使用。

## 二、原版技能牌特效库

### 2.1 全屏与战场气氛

| 别名 | 原版卡牌 | 实现 | 可调整程度 | 适合 MGR 的方向 |
|---|---|---|---|---|
| 全屏爆发 | 肾上腺素 `Adrenaline` | `VfxCmd.PlayFullScreenInCombat("vfx/vfx_adrenaline", owner)` | 原资源整体复用，直接改色不方便 | 超光速、流星一过一类瞬时爆发牌；建议借结构制作紫青版本，不直接照搬颜色 |
| 彩色烟雾暗角 | 迷雾 `Haze` | `NSmokyVignetteVfx.Create(colorA, colorB)`，并给每个敌人生成 `NSmokePuffVfx` | 暗角两种颜色可直接指定；烟雾颜色为预设 | 全体减力量、诅咒或净化效果，尤其适合塞壬之歌、长梦、黎明前线结束演奏 |
| 紫色梦魇暗角 | 夜魇 `Nightmare` | 紫色 `NSmokyVignetteVfx` + `NNightmareHandsVfx`，放在 `GlobalUi` | 暗角可改色；手部资源主题固定 | 妄想、梦境、发现类卡可借用暗角结构；不建议直接复用恐怖手掌 |

全屏层会覆盖战场或 UI，应遵守以下限制：

1. 选牌界面打开期间不要播放遮挡性暗角。
2. 演奏牌每次触发时不得反复创建长时间全屏层。
3. 同一时刻最多保留一层暗角，新的效果应复用或替换旧层。

### 2.2 角色中心的即时效果

| 别名 | 原版卡牌 | 实现 | 语义 | MGR 适配 |
|---|---|---|---|---|
| 血色冲击 | 放血、血墙、烙印、恶魔护盾 | `VfxCmd.PlayOnCreatureCenter(owner, "vfx/vfx_bloody_impact")` | 自伤、献血、生命代价 | 罪与罚、狂性实际扣血时高度适合；不应给普通转化牌使用 |
| 凝视 | 邪眼 | `vfx/vfx_gaze` | 精神、观察、条件生效 | MGR 的攻击牌《注视》已经使用；普通技能不宜重复滥用 |
| 飞行斩光 | 暴露、震荡波 | `vfx/vfx_flying_slash`，在角色中心播放 | 强制驱散、向外扩散的冲击 | 可借结构表现全体削弱，但原斩击图案与歌唱主题一般 |
| 普通强化 | 多数没有专属 VFX 的技能 | `Cast` 或 `PowerUp` 动作，加系统自带数值反馈 | 通用、短促 | MGR 普通格挡、抽牌与生成音符牌应优先采用此级别 |

## 三、原版能力牌的视觉层级

### 3.1 打出能力牌时

原版能力牌打出后仍会经过通用的能力牌飞向角色/能力区动画。只有少数牌额外加入专属效果：

| 类型 | 原版例子 | 实现 | 复用建议 |
|---|---|---|---|
| 通用强化爆发 | 腐化、绯红披风、坚定不移 | `NPowerUpVfx.CreateNormal(owner)` + `PowerUp` 动作 | 适合没有独特画面的高价值能力；原节点会在 `_Process` 中重写自身颜色，不能只靠设置根节点 `Modulate` 随意染色 |
| 地面火焰强化 | 燃烧 | 通用强化 + `NGroundFireVfx` | 只用于火焰或高温主题 |
| 持续燃烧 | 薪火之源 | `NFireBurningVfx` | 颜色主题固定，不适合大量迁移 |
| 角色背后专属装饰 | 刀扇 | `OnEnqueuePlayVfx` 中添加 `NFanOfKnivesVfx` | 资源是刀具主题；可以借“放在人物背后”的分层方法，不能直接当 MGR 装饰 |
| 独占能力演出 | 地狱狂徒 | `NHellraiserVfx` | 高度绑定原卡，不建议直接迁移资源 |

`OnEnqueuePlayVfx` 适合在能力正式结算前播放一次演出，但对 MGR 有额外限制：演奏能力牌已经有专门的“飞入演奏堆”处理，不能重新启用原版能力牌插入角色身体的动画。

### 3.2 能力持续存在时

原版形态能力采用独立的持续节点：

- 恶魔形态：`NDemonFormVfx`
- 回响形态：`NEchoFormVfx`
- 死神形态：`NReaperFormVfx`
- 群蛇形态：`NSerpentFormVfx`
- 虚空形态：`NVoidFormVfx`

共同结构是：

1. `PowerModel.AfterApplied` 创建 VFX。
2. 将 VFX 挂到角色的 `Visuals.AddFormVfx`。
3. `AfterRemoved` 关闭或释放节点。
4. 能力实际触发时调用 `OnEffectTriggered()`，重启一组粒子或亮度动画。

这个架构非常值得 MGR 学习，但原版节点大多依赖 Spine 骨骼跟随。MGR 当前使用 PNG 序列人物动画，不能直接假定原版骨骼名称存在。正确迁移方式是复用生命周期设计，并把 MGR 自定义节点挂到人物现有的视觉锚点，而不是直接实例化原版形态节点。

### 3.3 能力实际触发时

原版最常用的反馈不是独占动画，而是 `PowerModel.Flash()`：

- `Flash()` 会触发 `NPowerFlashVfx`，在能力拥有者附近显示该能力的大图标，约 0.4 秒放大并淡出。
- 它同时明确告诉玩家“刚才是哪个能力触发了”，成本远低于全屏特效。
- MGR 的卫星少女、罪与罚、极彩色、卡农形态、混沌轱辘、第六感等能力已经在关键钩子里使用 `Flash()`，方向是正确的。

少数能力会在 `Flash()` 之外增加效果：

| 触发类型 | 原版例子 | 实现 | 可迁移方向 |
|---|---|---|---|
| 持续形态脉冲 | 恶魔形态、群蛇形态、回响形态 | `Vfx?.OnEffectTriggered()` | 卡农形态、彼岸、卫星少女等持续核心能力 |
| 逐敌人气态命中 | 毒雾 | 对每名敌人创建绿色 `NGaseousImpactVfx` | 老大哥在看着你、状态音符标记，改为灰红或黑红 |
| 全体斩击反馈 | 速行者、雷霆 | 对所有目标播放斩击 + SFX | 只适合真正造成全体伤害的能力，不用于抽牌或生成牌 |
| 注入自动攻击特效 | 地狱狂徒 | 在 `BeforeAttack` 修改自动打出的攻击命令 | MGR 若将来需要“演奏自动打出时采用另一套命中特效”，可以借这个钩子思路 |
| 闪电反噬 | 电流相关能力 | `vfx/vfx_attack_lightning` 后自伤 | 电子天使等数字主题可以借视觉语言，但效果语义必须匹配 |

## 四、MGR 技能牌对应建议

以下是推荐方案，不代表已经实现。

### 4.1 优先值得增加专属特效

| MGR 卡牌 | 推荐参考 | 建议表现 | 原因与限制 |
|---|---|---|---|
| 流星一过 `MeteorAftermath` | 肾上腺素 | 紫青色全屏加速线或由角色向外爆开的短促光流 | 立即获得能量并补满手牌，瞬时爆发语义非常明确；只播放一次 |
| 长梦 `LongDream` | 迷雾 | 收缩范围的淡紫烟雾波覆盖全场，角色与敌人分别闪一次 | 同时降低所有生物力量；它有演奏，必须使用轻量版并压缩等待 |
| 塞壬之歌 `SongOfSiren` | 震荡波 | 每次结算在角色中心播放原版震荡波同源的飞行斩击提示，并保留敌人周围的蓝紫声浪 | 全体失去力量；演奏触发也播放，但特效不阻塞后续结算 |
| 黎明前线 `DaybreakFrontline` | 恶魔之焰的完整卡牌消耗特效 | 只在演奏结束时把所有目标牌汇聚到中央，再以略慢的烟尘溶解逐张消耗 | 不在每次演奏时播放；效果绑定“结束演奏”钩子，实际牌堆结算仍独立执行 |
| 银河电灯 `GalaxyLamp` | 可染色暗角 | 一次紫色暗角闪烁，所有现存音符同时向星空色过渡 | 转换本身已有音符 UI，额外效果只负责统一气氛 |
| 春岚 `SpringStorm` | 自定义全屏图片闪光 | `images/vfx/SpringStormVfx.png`只短暂闪现和抖动，不再跟随临时强音覆盖到回合结束 |
| 疑神暗鬼 `PaleDread` | 原版夜魇手爪短版 | 以0.74初始透明度出现并在0.72秒内淡出；卡牌入手与弃牌动画仍承担主要信息反馈 |
| 拍鬼怪的马屁 `PleasingGhosts` | 原版夜魇手爪 | 取消导致几乎不可见的近黑乘色，恢复原版完整色彩与2秒时长；两张诅咒的预览等待缩短到0.32秒 |
| 星降之海 `StarfallSea` | 星海轨迹 + 统一星空音符坠星 | 打出时保留星海轨迹；下回合只生成音符，每个星空音符自动触发2至4颗小坠星 | 坠星来自音符系统，不再是本牌专属逻辑 |

### 4.2 主要依赖现有 MGR 系统即可

| 卡牌组 | 原因 |
|---|---|
| 小小游行、点滴奇迹、合唱、音符魔法、彩虹音阶 | 核心结果就是生成、复制或读取音符，音符槽和线谱反馈已经足够强。 |
| 献祭、乙女解剖 | 应强化“卡牌移动/消耗 → 音符出现”的连续动画，不需要套毒雾或攻击特效。 |
| 白虎野之女 | 已增加仅在其位于演奏队列时存在的紫色萤火场；角色周围密、屏幕远处疏，离队后淡出。 |
| 甜蜜魔法 | 成功获得强音时保留霓虹灯柱，并追加人物位置向外喷射的彩色庆祝星屑。 |
| 游生梦死 | 还原音符前在人物位置播放青紫蜃景环和星系环；选牌与入手动画仍是信息主体。 |
| 妄想素描、光线歌、活动小丑 | 重点是选择界面与牌堆移动。全屏粒子容易遮挡真正需要查看的卡牌。 |
| 预演 | 抽牌动画本身就是信息反馈，应保证玩家看得清牌，不叠加大特效。 |
| 白南风 | 已接入白青色旋风线；牌与格挡按“丢一张、获得一次”交替结算，保证玩家能看清对应关系。 |
| 孤独宇宙、两个人的星 | 星空音符生成、人物星座密度和音符槽变化可以承担主要反馈。 |
| 群青赞歌、甜甜圈洞、防御、安眠曲 | 以格挡 VFX、演奏牌脉冲和条件发光为主，暂不需要独占全屏演出。 |

## 五、MGR 能力牌对应建议

### 5.1 触发反馈优先级高

| MGR 能力 | 推荐参考 | 建议表现 |
|---|---|---|
| 罪与罚 `CrimeAndPunishment` | 放血的血色冲击 + `Flash()` | 回合开始扣血时先闪能力图标，再在人物中心产生小型暗红冲击；获得强音仍用强化脉冲。 |
| 狂性 `Frenzy` | 放血 | 只有因狂性而打出原本不可打出的状态/诅咒并扣血时，才产生短促血色冲击。 |
| 极彩色 `Prismatic` | 形态 `OnEffectTriggered()` + 环形星爆 | 满足三种音符时，能力图标闪烁、人物附近出现彩色脉冲，并向周围抛射一大圈彩色星星。 |
| 老大哥在看着你 `WatchingU` | 后景巨眼 + 逐目标凝视 | 打出能力时，在角色和敌人背后的原版后景VFX容器生成一双巨大暗红眼睛并眨动一次；状态音符触发时仍给每名敌人播放凝视反馈。 |
| 八十八键的宇宙 `UniverseOf88Keys` | 全体逐目标反馈 | 回合结束造成伤害前先闪能力图标，再让每名敌人出现一次紫白星光或轻型钝击。 |
| 卫星少女 `SatelliteGirl` | 持续形态架构 | 本回合效果可用时保留一颗较大、清晰的轨道星；轨道半径、倾角、速度和初相位每场战斗随机，轨道还会缓慢变形。耗尽能量触发后星体淡出。 |
| 卡农形态 `CanonForm` | 月相时间轮 | 每复制一批牌时放大、明显增亮并以较慢角速度持续旋转完整一圈；不按复制牌数量重复播放。 |

### 5.2 以现有系统反馈为主

| MGR 能力 | 原因与建议 |
|---|---|
| 混沌轱辘 | 保留轮形触发脉冲；每层能力另外生成一份颜色缓慢流动、透明度很低且独立漂移的人物虚影。 |
| 第六感 | 抽牌后短暂展示再弃牌最重要；不要用全屏特效盖住牌。 |
| 电子天使 | 快速生成牌动画 + 数字感小闪光即可。 |
| 想象、创造 | 整个选牌与类型转换流程使用全屏黑白滤镜；新卡真正生成后恢复颜色并按类型闪一次。 |
| 失败作少女 | 二选一期间持续使用像素化、RGB 错位、扫描线、噪点、撕裂和偶发蓝屏；效果实际结算完才关闭。 |
| 彼岸 | 双倍音符由音符槽连续生成体现；持续装饰包含双轨光环和独立漂移的蓝色人物虚影。 |
| 里表情人 | 攻击音符封锁由能力图标表达；同时生成一份独立漂移的淡红色人物虚影，可和其他能力虚影叠加。 |
| 心象蜃気楼、涅染夜曲 | 能力效果发生在具体音符触发时，优先强化能力音符/诅咒音符自己的反馈。 |
| 轮回 | 攻击音符被和弦消耗时闪烁能力图标并获得活力；无需额外常驻特效。 |
| 舞台预热 | 本身属于演奏能力牌，线谱和演奏结束反馈优先，避免恢复原版能力牌飞向角色的冲突动画。 |
| 宇宙香料 | 主要是一次性移除音符并获得属性，使用音符槽收束 + 通用强化脉冲即可。 |

## 七、建议实施顺序

### 第一阶段：低风险触发特效

1. 罪与罚、狂性：血色冲击只绑定实际扣血节点。
2. 极彩色：在满足条件并获得力量/敏捷时播放短彩色脉冲。
3. 老大哥在看着你：状态音符应用标记时逐敌人生成可染色气态冲击。
4. 八十八键的宇宙：回合结束伤害增加轻型全体命中。

这些改动不影响选牌、牌堆和演奏队列，风险最低。

### 第二阶段：少数招牌技能

1. 流星一过：短促全屏爆发。
2. 长梦、塞壬之歌：共用一个可配置的轻量全场声雾效果。
3. 银河电灯：一次音符统一变色的全局脉冲。
4. 黎明前线：只在演奏结束时汇聚目标牌，并播放略慢的恶魔之焰式消耗。

### 第三阶段：持续能力装饰

1. 卡农形态的回声环。
2. 卫星少女的轨道星。
3. 彼岸的双轨音符光环与人物左下方同步蓝影。

这一阶段需要建立适配 PNG 序列人物的 MGR 自定义视觉锚点和生命周期管理，不能直接套用依赖 Spine 骨骼的原版形态节点。

## 八、实现与性能规则

1. 结算逻辑继续串行，纯视觉尾迹可以并存。
2. 演奏牌触发时，全屏暗角和大型投射物必须压缩等待；同类持续节点要复用，不能每次创建一层。
3. 技能产生卡牌、移动卡牌、抽牌或弃牌时，先保证牌本身看得清，再考虑粒子。
4. 能力触发默认先使用 `Flash()`；只有 `Flash()` 无法表达目标或效果方向时，才增加额外 VFX。
5. 原版资源有三类：可直接传入颜色的节点、只有预设颜色的节点、完全绑定卡牌主题的专属节点。不要假定设置根节点 `Modulate` 就能正确改色。
6. 复用原版场景时检查 `ExtraRunAssetPaths`；需要自定义颜色、尺寸或层级时，优先实例化后修改具体子节点或编写轻量 MGR 节点。
7. 所有持续能力 VFX 必须在战斗结束、能力移除、角色死亡以及地图/卡组覆盖界面打开时正确隐藏或释放。

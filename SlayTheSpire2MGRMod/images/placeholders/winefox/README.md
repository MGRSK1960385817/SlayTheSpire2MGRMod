# Temporary WineFox placeholders

These files are temporary development placeholders copied from
[LuoTianOrange/STS2_WineFox](https://github.com/LuoTianOrange/STS2_WineFox).
They are deliberately kept in one directory so they can be replaced without
changing MGR gameplay code.

Source assets are licensed under
[CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/).
The energy-counter scene/code layout is adapted from WineFox's MIT-licensed
implementation. No asset was modified beyond renaming the copied file.
